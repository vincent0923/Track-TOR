# 推拉机 track-TOR 产品说明

这份文档记录产品为什么存在、取舍时听谁的，以及现在已经做到什么样。改产品之前先读这里，方向变了也先改这里。

## 产品定位

**骑行佬练就薄肌上身的爽感健身记录 App。**

- **给谁用：** 骑行爱好者。腿和心肺已经练得不错，上半身长期闲置。
- **要达成什么：** 骑行佬本来就瘦，缺的是上身肌肉。目标是练出薄肌上身，线条好看，穿骑行服不心虚，引体越做越多。
- **靠什么坚持：** 爽感。每完成一组都有烟花和音效，进度看得见，记录本身就让人想继续。

## 设计取向

有冲突时，排在前面的优先。

1. **省事第一。** 操作越少越好，授权越少越好，一次授权管得越久越好。
2. **爽感是核心功能，不是装饰。** 烟花、音效和进度条要保留并继续打磨，别为了“简洁”砍掉。
3. **围绕上身力量和引体。** 新功能先问：它能帮用户多练、练得更爽吗？不能就先不做。
4. **一天的练习都放在那一天。** 同一天的正式动作和加练记在同一个面板里，方便统一管理；点日历上的那一天就能看到。
5. **图表只算连续、可信的数据。** 断档的日子不凑数，宁可显示“–”。
6. **数据留在用户手机里。** 没有账号，也没有我们的服务器。备份是用户自己手里的一个文件。
7. **零门槛分享。** 把网址发给别人就能用，不用安装，不用注册。
8. **界面能用图标说清就不写字。** 操作就放在它影响的内容旁边，比如在图表上直接记录，不单独开一个表单。不加不必要的标签和辅助说明，让布局和按钮自己说话；真要解释的放进「i」里。

### 关于安全的态度

健身和饮食数据不算敏感信息。这里的用户要的是省事，不是层层防护，所以：

- 高驰授权长期保存在手机里，到期前自动续期。
- 备份文件带上高驰授权，换手机恢复后不用重新授权。
- 如果真要在省事和谨慎之间取舍，默认选省事，并如实告诉用户影响。

只有可能直接造成真实损失的事才例外，比如泄露财务信息。真出现这类功能，要单独讨论。

## 现在的样子

| 模块 | 做法 |
|---|---|
| 形态 | 静态网页，可装到手机主屏，部署在 GitHub Pages；`index.html` 放网页结构，`css/` 放样式，`js/` 按功能分成训练、图表、高驰、饮食、备份等几个文件，不需要构建 |
| 数据 | 存在浏览器 `localStorage`，所有记录放在同一份数据里：每天的身体和高驰数据（引体、体重、腰围、睡眠、HRV、静息心率、活动热量、步数）一张表，饮食一张表；用 txt 进度文件备份和恢复 |
| 训练 | 20 天推拉计划，共 40 次训练，逐级解锁；每个训练日都有加练区，默认引体向上。训练页最上面是月历：练过的日子标推（橙）拉（蓝）圆点，只有加练的日子标空心圈；点某天在日历下展开当天完成的训练和当天的加练，没有训练的日子也能记加练和备注（存在 `dayx[日期]`），只有备注的日子也会标出来。今天的加练到午夜前随便改、随便保存（磁盘图标）；过去日子的加练和备注只读，点「修改记录」确认后才能改。保存按钮统一用磁盘图标。日历下面只列接下来 5 次没练的训练 |
| 热量消耗估算 | 总消耗 = 基础代谢（Mifflin）+ 手表热量 + 消化耗能（按营养素：蛋白质热量 × 25%、碳水 × 8%、脂肪 × 2%；没记营养素的日子按摄入 × 9%），或用户手填的当日总消耗。手表热量按高驰全天活动卡路里拆开（高驰的活动热量不含基础代谢，只在录了运动和步频超过 130 时记）：日常活动全算；当天运动记录的热量 × 0.7（心率估算偏高）；健走、家务等自定义活动、瑜伽这类低强度运动 × 0.5；骑行详情里有功率数据的按有功率计算，× 0.9。读不到运动记录的日子整天按 0.7；同步时读不到运动记录而全天热量变了的日子，也退回整天 0.7 |
| 饮食数据源 | 「饮食记录」一排是三个胶囊按钮：「饮食记录 +」切换全部展开和全部收起；「添加 +」整个胶囊切换展开和收起手动记录面板（在页面里展开，不弹窗）；「同步 +」左半边立刻拉取线上表格（没填有效链接时变灰），加减号展开和收起「线上数据」面板（粘贴任意表格网址、拉取）；还没有记录时线上数据面板默认打开。存了有效链接时，每次打开「饮食」页都在后台拉一次（半分钟内重复点不再拉），进度动画显示在「饮食」标签上；打开推拉机时，如果距上次拉取超过两小时也会在后台拉一次（失败也最多每两小时试一次）。推拉机不看表格放在谁家，Google 表格、腾讯文档、自己的电脑或服务器都行。读取尽量宽容，把纠错放在推拉机里而不是让写表格的人或 AI 守规矩：列名中英文都认、顺序随意、可带单位，多余的列忽略，没有列名就按默认顺序；日期常见写法都认（含没写年份、表格内部日期数字），同一天后面几行日期留空沿用上一行；数字里的单位、全角、千分位都能读，没填热量按 4/9/4 算；合计行自动跳过；逗号/制表符/分号/竖线分隔的文本、网页表格、JSON 都认。表格里有的日期覆盖本地饮食，其他日期和非饮食数据不动。「拉取」顺便从高驰拉活动热量（没登录就只拉饮食），顶部「同步」顺便拉饮食表（填了链接才拉）；两个按钮工作时有从左往右的填充动画，先慢后快，停在九成左右等结果，完成后填满；只给进行中的感觉，不代表真实进度。热量缺口总结（摄入与消耗图标题下的卡片）只算过完的日子，今天不算。说明面板附给 AI 的记账 prompt（Google 表格版或腾讯文档 WorkBuddy 版，按时区默认），是几行固定文字、不带链接，默认用户还没有表格：第一次由 AI 建好「饮食记录」、写列名、设成知道链接的人可查看并发回链接；只要求记下吃了什么，不让 AI 汇报额外的东西；只讲内容不讲格式，列名用中文「日期｜食物｜蛋白质｜脂肪｜碳水｜蔬菜｜热量」 |
| 蛋白质 | 「摄入与消耗」图右轴是蛋白质 g：每天记下的蛋白质（逐项记录里有蛋白质才画）和增肌够用区间（浅色带）：当天体重 × 1.6 到 2.2 g。到下沿就够增肌；超过上沿不算问题，减脂期间多吃蛋白质更顶饱、消化耗能高、更保肌肉。实心点是吃够了，空心点是没吃够 |
| 饮食 | 在数据页填总热量和蛋白质、脂肪、碳水、蔬菜（总热量必填），填齐蛋白质、脂肪、碳水后可一键估算总热量（已填的总热量不会被覆盖，只显示差额），也能逐项记明细，结合高驰活动数据算热量缺口 |
| 页面结构 | 一级标签：训练 / 图表 / 资料。「图表」下分饮食、健康（睡眠、HRV、静息心率）、力量（最上面是「一年打卡」热力图：最近 53 周每天一格，当天打勾的组越多颜色越深，标题旁是打卡天数，可以横向滑动，打开时停在最近几周；下面是引体、体重、腰围，都是自己填的身体数据）三页。导航图标统一用简约线条风格；「资料」里是个人资料、目标、备份进度、全部记录、要点、图表和同步设定、音效 |
| 图表 | 引体、体重和腰围点手写图标记录，日期默认当天，空着的输入框里有测量提示，超出合理范围存不进去 |
| 单项同步 | 「健康」里睡眠、HRV、静息心率三张图，标题左边是图标，右边是同步按钮，只拉这一项；没连高驰时点它打开连接窗口 |
| 同步设定 | 在「资料 › 图表和同步设定」选从高驰同步哪些：睡眠、HRV、静息心率、体重。关掉的项不同步，也不显示它的图表；已有数据保留 |
| 音效 | 全部用 Web Audio 现场合成，不带音频文件：推拉机自己的配方，加开源 ZzFX（MIT）的 52 个和 jsfxr（公有领域）的 54 个预设，都按各自的预设规则用固定种子生成，第一次播放时合成并缓存。「资料 › 音效」里给每种点击（训练打勾、烟花、切换标签、展开、保存、删除、同步开始/完成/失败等）选声音，选的时候试听；存在 settings 里，跟着进度文件走；「恢复默认音效」还原。右上角喇叭是总开关 |
| 新用户 | 第一次打开填性别、出生年月、身高、体重和目标，都能留空；连了高驰会自动补上性别、出生年月和身高 |
| 目标 | 引体、腰围、体重、减脂四个目标；减脂用“有记录以来”的热量缺口折算已经消灭的脂肪（7700 kcal = 1 kg，只算过完的日子）。首页目标卡片显示哪几个由用户在「目标」面板里选，0–4 个，都不选就隐藏整块。点卡片左边的图标直接跳到该目标的输入框 |
| 个人资料 | 性别、出生年月、身高、现在体重放在数据页的「个人资料」面板，默认模糊显示，点眼睛或点输入框才显示 |
| 高驰 | 浏览器直连，支持中国大陆、欧洲和美国区；一次授权，自动续期；可在备份面板登出，选择保留或清除同步来的数据 |
| 语言 | 中文和英文 |
| 主题 | 十四套，分六组：默认（浅色、深色）、Interior（亮、暗）、极简、手作、玩具（玩具、夜间玩具、赛博玩具、牛仔、霓虹玩具）、复古（复古绿屏、赛博终端、雨夜琥珀）。Interior 参考 interior.dev 的微交互组件：石色与白、细线框，按键是一块白色键帽压在石色底座上、按下落到底座；标签和时间范围是凹槽里一块深色滑块，滑过去时文字反色；面板展开时内容区略微下沉；数字变化时短暂染色（变大绿、变小红）；Geist 字体，点按声是轻点。其余四种风格参考 Ovio：极简是白底细线、黑色胶囊标签、Geist 字体；手作是奶油纸、胶带、柔和叠影、橙色胶囊标签、Bricolage Grotesque 字体，提示条像一张便签；玩具是塑料按键（按下下沉、松手回弹）、打勾框是按键、选中的标签是一块会滑过去的塑料片、日历里的训练日像塑料钉、提示条和进度条带回弹，Archivo 字体；复古是终端屏：像素字体 VT323、字发光、直角、双线框、扫描线，标签块一格一格跳过去。右上角主题按钮：点一下换下一个（提示条显示名字），长按进「资料 › 主题」面板，面板里每个主题一张预览小卡，点了就换。只换外观，数据是同一份。玩具、复古、手作三种风格连主要图标（标签、右上角按钮、目标图标）也换成配套的一套：玩具是粗描边加彩色填充的塑料感图标（Streamline Plump），复古是像素图标（Pixelarticons），手作是手绘涂鸦图标（Doodle Icons）；套里没有的（哑铃、体重秤、折线图、引体）按同样风格补画。每种风格有自己的默认点按声：玩具是塑料声（标签是塑料片滑入，按钮是塑料按键，保存是积木咔哒），复古是八位哔哔和键盘滴、保存是金币，手作是翻页和纸张轻拍、保存是盖章，极简是轻点；自己选过的声音照旧 |
| 数字滚动 | 目标百分比、热量缺口、一年打卡天数变化时滚到新数字（0.4 秒），打开时从 0 数上来；系统开了「减少动态效果」就直接显示 |

**授权能撑多久：** access token 约 30 天，refresh token 约 180 天。网页在剩余不足 15 天时自动续期，所以约半年内打开过一次，就不用重新授权。同一份授权恢复到两台设备上时，一台续期后另一台可能要重新授权一次。
