# 推拉机 track-TOR 产品说明

这份文档记录产品为什么存在、取舍时听谁的，以及现在已经做到什么样。改产品之前先读这里，方向变了也先改这里。

## 产品定位

**骑行佬练就薄肌上身的爽感健身记录 App。**

- **给谁用：** 骑行爱好者。腿和心肺已经练得不错，上半身长期闲置。
- **要达成什么：** 骑行佬本来就瘦，缺的是上身肌肉。目标是练出薄肌上身，线条好看，穿骑行服不心虚，引体越做越多。
- **靠什么坚持：** 爽感。每完成一组都有烟花和音效，进度看得见，记录本身就让人想继续。

## 设计取向

有冲突时，排在前面的优先。

1. **省事第一。** 操作越少越好，授权越少越好，一次授权管得越久越好。
2. **爽感是核心功能，不是装饰。** 烟花、音效和进度条要保留并继续打磨，别为了“简洁”砍掉。
3. **围绕上身力量和引体。** 新功能先问：它能帮用户多练、练得更爽吗？不能就先不做。
4. **一天的练习都放在那一天。** 同一天的正式动作和加练记在同一个面板里，方便统一管理；点日历上的那一天就能看到。
5. **图表只算连续、可信的数据。** 断档的日子不凑数，宁可显示“–”。
6. **数据留在用户手机里。** 没有账号，也没有我们的服务器。备份是用户自己手里的一个文件。
7. **零门槛分享。** 把网址发给别人就能用，不用安装，不用注册。
8. **界面能用图标说清就不写字。** 操作就放在它影响的内容旁边，比如在图表上直接记录，不单独开一个表单。不加不必要的标签和辅助说明，让布局和按钮自己说话；真要解释的放进「i」里。

### 关于安全的态度

健身和饮食数据不算敏感信息。这里的用户要的是省事，不是层层防护，所以：

- 高驰授权长期保存在手机里，到期前自动续期。
- 备份文件不带高驰授权（用户要求，v1.44a 起），换手机恢复后重新连一次；饮食表格链接带上，恢复后不用再贴。
- 如果真要在省事和谨慎之间取舍，默认选省事，并如实告诉用户影响。

只有可能直接造成真实损失的事才例外，比如泄露财务信息。真出现这类功能，要单独讨论。

## 界面

推拉机只有一个界面（`index.html`）。原来的经典界面和它的 29 套主题在 v1.43a 删掉了，完整代码留在 GitHub 分支 `backup-classic-v1.42a`。经典界面时期的进度文件照样能导入。高驰登录的回调地址是网站根目录。第一次打开（没有任何记录）弹欢迎页填资料和目标，只弹一次，都能留空。每 5 天提醒一次备份（「以后」从现在重新算 5 天）。

**现在的样子：**

- **结构：** 底部一条悬浮的深色胶囊，三个标签：训练、饮食、进展（数据和目标合在一起），选中的标签滑到一块强调色胶囊下。顶栏只有日期、页面名、一个同步状态小圆点（点了同步高驰，没连过就弹出连接；同步时在转，今天同步过是绿色；打开时连着高驰且上次同步超过 2 小时，后台悄悄同步一次）和头像。头像打开设定：外观（跟随手机、亮、暗；庆祝效果开关）、G 积分商场、语言（简中、繁中、Eng 一行三格），「更多」里是训练计划、个人资料、目标、备份进度与高驰（保存进度文件、从进度文件恢复并先确认内容；连接高驰，或登出时选保留数据或清除同步来的数据）、天气、饮食表格（粘贴链接、保存并拉取、上次同步状态）、图表、同步和手表热量（从高驰同步哪些，关掉的睡眠 HRV 静息心率不在进展页显示；手表热量打折或全算）；最下面是版本号。
- **训练：** 最上面是一叠深色卡片，像扑克牌：最上面一张写「可练」，是几种训练日里最久没练的那种的下一次；后面是其他训练日现在能练的那次，再后面是每种训练日之后一次的预告（带锁，能看动作，展开后写「练完 某某 解锁」）。下面一张是毛玻璃，左右划走最上面一张时它在 0.3 秒内变清晰，转一圈回到第一张；点露在下面的牌边也能翻。可练的卡片右上角是「▶ 开练」（练了一半显示「已做/总组数」），预告卡片同一位置是 ✨。卡片默认收起，高度固定：名字、动作数 · 组数 · 用时，下面只露出两行动作、越往下越淡；点卡片展开全部动作，再点收起。✨ 点开「建议练（可手动调整）」：一句话说明这些是按前 3 次训练的表现建议的、每练完一次重新算；「i」展开背后的依据（渐进超负荷、双重递进、次数范围、训练量、看前 3 次、按感觉调、减量，附研究出处）。日历也是一叠毛玻璃卡片，默认展开是一个月，收起是一周，尺寸照 SplitFlow 的活动日历：小圆格，练过的日子整格染成那种训练日的淡色（只有加练是一圈细线）；点任何一天（今天和以前），日历底部才出现一条小简报：练过的日子是同色小图标和那天的动作名，只有加练的日子是加练的动作，什么都没有的是「休息日」（今天是「今天还没练」），一行放不下就截断；右边一个笔，按了才打开那一天去改或加练；再点同一天收起；手指往右划回到上一周或上个月，往左划往后（不会划到未来）；离开本月（本周）时右上角出现一个半透明的复位按钮，点了回来，只是回来、不打开什么；点日历上的今天那格才打开今天（加练）。练过的日子下面有推、拉颜色的小圆点（只有加练是空心圈）。点某一天（今天和以前）弹出这一天：完成的训练（每个动作每组做了多少，没打勾的组是灰的）、加练、当天的摄入和缺口、体重腰围引体；训练旁边点「修改」，每组变成「− 次数 +」，点次数补打或取消勾，点「完成」保存并让引擎重新排后面的训练。加练：引体向上、俯卧撑、深蹲、平板支撑、悬吊五个快捷项，或「其他」自己起名（问一句按秒还是按个），每项一个「− 数 +」和「记一组」，新的一组从上次记的数开始，已记的组点一下撤销；有完成训练的那天记进那次训练（`xs`），没有就记进 `dayx[日期]`。练完的总结卡上有「加练」直接打开今天。
- **专注模式：** 点「开始」进入全屏，一次只看一个动作：很大的次数、两侧加减（按秒计的动作一次 5 秒，后面没做的组跟着改）、屏幕下方拇指位置一个大勾。打勾后自动开始组间休息倒计时（引体 150 秒，悬吊和离心引体 90 秒，其余 60 秒；能加 30 秒或跳过），结束时震一下、响一声。按秒计的动作点一下开始计时，到点自动打勾，提前点也算。做过的组显示次数，点一下撤销。左右滑换动作，顶上一排短条表示做到哪。每一下都直接存进训练记录（打勾顺序也记），中途退出不丢。每打一个勾放一支烟花，做完一个动作再从下面喷一小撮彩带、放三支烟花，并问一句感觉（轻松、刚好、很难，可以跳过；拉伸不问），整次练完记为完成（日期是今天），两边彩带礼炮加一场烟花（最后一支大的），和一张总结卡：组数、次数、用时、引体单组最多和是否破纪录、下一次练什么。
- **饮食：** 最上面一个大数字是今天的缺口（没同步消耗时显示摄入），旁边是蛋白质圆环，下面一根摄入和缺口的对比条，右下角一个不起眼的「+」打开饮食面板。然后是缺口卡片（高度固定，柱子在里面缩放），也是毛玻璃卡片叠：过去 7、14、30 天和有记录以来四张，手指往右划看更长的，往左划回来，大数字像翻牌一样翻出来，柱子跟着换（7、14 天下面写星期几，30 天每天一根细柱，有记录以来按周一根），14 天以上的脂肪克数前面按体重对账写「约」「激进估计」「保守估计」，选的天数会记住。最后是记录，也是一叠毛玻璃卡片：一张七天，更早的压在下面，手指往右划看更早的，往左划回来；不在最近一张时右上角出现同样的半透明复位按钮；每天一行，点开从底部弹出那天的明细（食物、蛋白、脂肪、碳水、蔬菜、热量；食物名太长就折成两三行）和「编辑这天」；右上角的分享按钮把这天的表格画成一张图，交给手机的分享面板（不支持时就下载）。饮食表格：打开饮食页时自动拉一次（半分钟内不重复），把饮食页往下拉就立刻拉；拉取时顶栏的同步小圆点在转；没填链接会提示去设定里填。热量算法见下表，跟手表热量开关走。
- **进展：** 最上面是深色卡片上的四个目标圆环（主项、腰围、体重、减脂），点了去设目标。主项默认是标准引体，在目标面板里换：从你练过的所有动作（训练、加在训练里的、休息日记的都算）和训练计划里的动作里选，按记了多少组从多到少排、每个后面写着组数（打勾就自动记单组最好的一次，训练引擎也不会把它换成更难的动作，只让次数或秒数一直往上加），或者选「其他」自己写名字和单位（次、秒、分钟、km、kg），只能手动记。按单组或单次最好算，不做累计。下面两列小卡：主项卡堆占整行，其余是体重（7 日均）、腰围、睡眠、HRV、静息心率；每张卡是当前值、和 30 天前比的涨跌、一条平滑的迷你曲线。长按任意一张进入编辑：卡片轻轻抖动，按住拖动换位置，左上角 × 隐藏；右下角浮着两个半透明按钮：「+」把隐藏的图表加回来，「✓」完成。顺序和隐藏的存在 `settings.tiles`。点开从底部弹出完整图表，用旋钮选 14、30、90 天或全部，涨跌跟着选的天数走，手指划过读某一天；引体体重腰围下面有「记一笔」（打开记录面板，选日期填一个数，留空就是删掉那天的记录），睡眠 HRV 静息心率有「从高驰同步」。
- **自由练（`js/engine.js`）：** 不选计划也能练，这是新用户的默认。建议从你记过的东西里长出来：最近 3 周练过的每个力量动作（正式训练和加练都算）进一个动作池，3 周没碰就淡出；散步、骑车、跑步这类按分钟或公里记的只记录、不排进建议。每次挑几个动作照你平时一次练几个（最近三天的中位数），至少 2 个动作、5 组，最多 12 组；先挑最久没练的部位（推、拉、腿、核心，自己起名的动作单独算），同一个动作不连着两天练；每个动作从自己上次的记录接着加，不换成别的动作。只练过一个动作时补一个别的部位的入门动作；什么都没记过时第一次是俯卧撑、深蹲、平板。训练卡写「按你最近练的建议」。最近 6 个练过的日子落成 2–3 种固定的组合（比如推、拉轮着来）时，训练页顶上出现一次提示「看起来你在练二分：推 · 拉」，点「存成计划」打开自定义计划面板并按部位分好，点 × 就不再提这一种。
- **训练计划：** 设定 › 训练计划里第一张是「自由练」，下面是预设，最多三种训练日，名字可改（改的是当前语言的名字）：打造上身薄肌：引体 + 俯卧撑（推练、拉练，没选过计划的老用户就是这套，选它不会打断现在的安排）；全身紧致（每次练遍全身）；宽肩翘臀：上下肢 AB（上肢、下肢）；雕刻全身线条：推 / 拉 / 腿。换计划要确认，之后没开练的计划训练重新排，从新计划的动作开始，同名动作以前的成绩照样用来定次数；卡片叠的顺序是最久没练的在上。新用户填完欢迎页接着选计划。最下面是「自定义：用你练过的动作」，点 1 天、2 天或 3 天打开编辑面板：上面是每种训练日的名字（可改），下面你练过的每个动作一行，写着上次几组几个，右边点 A / B / C 放到哪天、「–」不练；默认按以前在哪天练分好（3 天时平板、悬吊、仰卧起坐这类核心和支撑放 C），拉伸自动加在每天最后；没有记录的新用户列出所有预设里的动作自己挑。保存后每个动作从自己上次的组数、次数、秒数接着练，按表现一点点加（多一个、多几秒、慢速、加一组），不换成别的动作、不加新动作。预设只是数据（训练日、名字、动作、起始组数次数），以后用户写的计划审核后放进 G 积分商场。
- **训练引擎（`js/engine.js`）：** 不靠 AI，App 自己排训练，取代原来固定的 20 天推拉计划（练过的记录保留）。每种训练日各自看前 3 次的表现排下 2 次，每练完一次重新排；开练过（打过勾或手改过数）的那次不动，下一次按它照计划完成来预告。规则：每组目标 5–10 个（核心动作 10–15，引体从 1 起，离心引体 3–8；支撑悬吊按 20–60 秒，一次 ±5 秒）。前 3 次里有 2 次每组都到顶（或上次到顶且觉得轻松）→ 升级：换动作阶梯上更难的一级（斜板 → 标准 → 下斜 → 钻石 → 弓箭手俯卧撑；离心引体 → 标准引体；反向划船 → 抬脚反向划船；仰卧起坐 → 悬垂举膝 → 悬垂举腿；派克俯卧撑 → 抬脚派克；深蹲 → 分腿蹲 → 保加利亚分腿蹲；臀桥 → 单腿臀桥；深蹲和臀桥按 8–15 个；同一次里已经有那一级就跳过），没有更难的就改慢速 3-1-1，再到顶就加一组。上次每组都达标且不觉得很难、后面几组没掉太多 → 下次每组 = 上次最少那组 +1（觉得轻松 +2），超过上限就升级。前 3 次里有 2 次一半以上的组差 2 个以上（或上次没达标且很难）→ 减 1，低于下限就退一级、去掉慢速或少一组。后面几组比第一组掉 30% 以上 → 保持。连续两次各有 2 个以上动作没达标 → 下一次组数 ×0.6。每个动作 2–4 组，每次 5–12 组（拉伸不算），超了先减支撑、再减核心、引体最后减。每个动作的理由存在 `why` 里（现在界面上不显示）。数据存在训练记录本身（`ex`、`feel`、`edited`），进度文件里是追加的 `pe` 字段。
- **G（积分）：** 只奖励力量、减脂、腰围上的真实进步，不奖励点按钮。练完一次训练 10；一周练够 3 天 30，连着几周每周多 5，最多 60（按周算不按天算，休息日不扣）；训练里打勾的主项单组每创一个新高 50（按秒的每 5 秒算一个；手填的、自己写的主项不算）；每减 0.5 kg 脂肪 50，取估算减脂和 7 日均体重变化里小的那个；腰围比第一次记录每少 1 cm 50（按最近 3 次的平均）；计划完成 10、20、40 次 100、200、400；每达成一个自己设的目标 500。币全部从记录里算出来、不另存，所以恢复进度文件就回来，备份格式不变；以后花掉的币和买过的主题存进 `settings`。余额和商场都在设定里（「G 积分商场」，右边是余额，图标是一枚写着 G 的金币），不占主界面；点开是主题、「大家写的训练计划」（即将上线）和每一项的进度（拿了多少、现在多少、下一档）；练完的总结卡写这次拿了多少。商场里的主题：像素 RPG、Low poly 小镇各 2,000 币，暂时「即将上线」；亮、暗两套永远免费。
- **天气（`js/p1weather.js`）：** 设定 › 外观 › 天气效果里搜城市（Open-Meteo 地名搜索，全世界都行）或者「用我现在的位置」（点的时候才定位一次，地名用 BigDataCloud 免费反查）。存在 `settings.weather`，最近一次天气缓存在 `tracktor-wx`，20 分钟更新。效果画在一张不接收点击的画布上（点到雨滴或雪花，它就化掉，点击照常传给下面的按钮），盖在页面和专注模式上面、弹出面板下面。只有雨、雪、雾三种，晴天和阴天什么都不画。雨是挂在玻璃上的水珠：形状不规则（小水珠接近圆），带阴影、边缘、透镜样的亮斑和高光；攒大了才往下跑，方向跟着手机倾斜（读手机方向传感器，iPhone 第一次点屏幕时问一次权限；放平就不跑），走走停停，沿路吞掉小水珠、留下水痕和更小的水珠；同时跑的最多 3–6 颗。雪的飘落方向也跟着倾斜。可以关，可以试看 15 秒。「减少动态效果」时只画一帧。
- **庆祝效果（`js/p1fx.js`）：** 从经典界面搬来的烟花：火箭从屏幕下方升起炸开，带爆炸声（噪声爆破、低频闷响和落下时的噼啪声，几支一起炸时共用一个压缩器不爆音）；大烟花更大、更久、闪烁。彩带礼炮用开源 canvas-confetti。目标圆环每跨过一个新的 2% 放 30 支烟花并提示，最高到过的档记在这台手机（`tracktor-milestones`，和经典界面同一份），体重来回波动不会重复放；第一次看到和刚打开的几秒只记不放。今天的加练每记一组也放一支。设定 › 外观的「庆祝效果」开关关掉全部（`tracktor-p1-fx`），系统要求减少动态时也不放。

## 现在的样子

下表是数据和算法。界面见上一节。

| 模块 | 做法 |
|---|---|
| 形态 | 静态网页，可装到手机主屏，部署在 GitHub Pages，不需要构建。`index.html` 加 `css/p1.css`；脚本：`js/core.js`（计划和存储）、`js/diet.js`（热量算法和饮食面板）、`js/engine.js`（训练引擎）、`js/p1*.js`（界面）等 |
| 数据 | 存在浏览器 `localStorage`，所有记录放在同一份数据里：每天的身体和高驰数据（引体、体重、腰围、睡眠、HRV、静息心率、活动热量、步数）一张表，饮食一张表；用 txt 进度文件备份和恢复 |
| 热量消耗估算 | 总消耗 = 基础代谢（Mifflin）+ 手表热量 + 消化耗能（按营养素：蛋白质热量 × 25%、碳水 × 8%、脂肪 × 2%；没记营养素的日子按摄入 × 9%），或用户手填的当日总消耗。手表热量按高驰全天活动卡路里拆开（高驰的活动热量不含基础代谢，只在录了运动和步频超过 130 时记）：日常活动全算，但最多按步数估算（每步约 0.00055 kcal × 体重 kg）的 1.5 倍再加 120 kcal——手表整天心率偏高时会把日常活动估高好几倍，超出的不算；当天运动记录的热量 × 0.7（心率估算偏高）；健走、家务等自定义活动、瑜伽这类低强度运动 × 0.5；骑行详情里有功率数据的按有功率计算，全算、不打折。读不到运动记录的日子整天按 0.7；同步时读不到运动记录而全天热量变了的日子，也退回整天 0.7。「手表热量」开关选打折（默认，即这套折扣和封顶）或全算 |
| 饮食表格 | 推拉机不看表格放在谁家，Google 表格、腾讯文档、自己的电脑或服务器都行。读取尽量宽容，纠错放在推拉机里：列名中英文都认、顺序随意、可带单位，多余的列忽略，没有列名就按默认顺序；日期常见写法都认（含没写年份、表格内部日期数字），同一天后面几行日期留空沿用上一行；数字里的单位、全角、千分位都能读，没填热量按 4/9/4 算；合计行在当天有明细时跳过，当天只有一行合计时就用它；以「备注：」开头、没有数字的行是这一天的备注（在推拉机里写过备注的日子不覆盖）；逗号、制表符、分号、竖线分隔的文本、网页表格、JSON 都认。表格里有的日期覆盖本地饮食，其他日期和非饮食数据不动。同步高驰时填了链接也顺便拉 |
| 热量缺口 | 只算过完的日子，今天不算。脂肪按 7700 kcal = 1 kg 折算；统计 14 天以上时，和同期 7 日均体重的变化差 15% 以内写「约」，估算多 15% 以上写「激进估计」，少 15% 以上写「保守估计」；不足 14 天或缺体重时写「约」 |
| 蛋白质 | 增肌够用区间是当天体重 × 1.6 到 2.2 g |
| 饮食面板 | 填总热量和蛋白质、脂肪、碳水、蔬菜（总热量必填），填齐蛋白质、脂肪、碳水后可一键估算总热量（已填的总热量不覆盖，只显示差额），也能逐项记明细 |
| 引体 | 引体图和引体目标记的是最大引体数，取两个数里大的：最近一次手动记录的数（后填的更低的数会替换之前的，测出退步也能记下）；最近 3 个拉练日里单组做得最多的引体数（计划里的和那几次的加练都算）。其他日子随手加练的引体不算 |
| 同步设定 | 选从高驰同步哪些：睡眠、HRV、静息心率、体重。关掉的项不同步，也不在进展页显示；已有数据保留 |
| 音效 | 全部用 Web Audio 现场合成，不带音频文件：打勾、做完一个动作、休息结束、练完、烟花各有一种 |
| 新用户 | 第一次打开填性别、出生年月、身高、体重和目标，都能留空；连了高驰会自动补上性别、出生年月和身高。接着选训练计划 |
| 目标 | 引体、腰围、体重、减脂四个目标；减脂用有记录以来的热量缺口折算已经消灭的脂肪 |
| 高驰 | 浏览器直连，支持中国大陆、欧洲和美国区；一次授权，自动续期；可在备份面板登出，选择保留或清除同步来的数据 |
| 语言 | 简体中文、繁体中文、英文 |

**授权能撑多久：** access token 约 30 天，refresh token 约 180 天。网页在剩余不足 15 天时自动续期，所以约半年内打开过一次，就不用重新授权。同一份授权恢复到两台设备上时，一台续期后另一台可能要重新授权一次。
